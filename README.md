# 🏥 Healthcare Analytics Project

---

## 📌 Project Overview
This Healthcare Analytics project focuses on analyzing **Electronic Medical Records (EMR)** data to derive **clinical and operational insights**.  
The project uses **SQL, Excel, Power BI, and Tableau** to transform raw healthcare data into **actionable insights** that support **data-driven healthcare decisions**.

---

## 🛠️ Tools & Technologies
- 🗄️ **SQL (MySQL)** – Data extraction, joins, KPI calculations  
- 📊 **Excel (Power Query)** – Data cleaning and transformation  
- 📈 **Power BI** – Interactive dashboards and KPI monitoring  
- 📉 **Tableau** – Trend analysis and advanced visual exploration  

---

## 📊 Key KPIs Analyzed
- 🧑‍⚕️ Patient Count & Visit Trends    
- 🏥 Department-wise Patient Distribution  
- 📅 Admission & Discharge Patterns  
- 📈 Operational Performance Metrics  

---

## 🔄 Project Workflow
1. Extracted EMR data and validated data quality  
2. Cleaned and transformed data using SQL and Excel  
3. Identified healthcare KPIs for reporting and visualization  
4. Built interactive dashboards in Excel,Power BI and Tableau  
5. Generated insights to improve operational visibility  

---

## 🔍 Key Insights
-🧑‍⚕️ Served 10,000 patients with 1,000 doctors, maintaining an optimal doctor load of 10
-💰 Generated ₹31M total revenue with ₹2,540 average billing per patient
-🩺 Migraine, Hypertension, and Asthma are the most common diagnosed conditions
-🧪 Lab results are evenly split across Normal, Abnormal, and Pending (~33% each)
-📞 Nearly 50% of patient visits require follow-up, indicating high continuity-of-care needs
-🏥 Vaccination and Surgery are the highest revenue-generating treatment types
